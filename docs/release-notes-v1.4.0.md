# 孤男音乐 v1.4.0 · 离线下载 · 平台健康探测 · 取链校验

> 这一版三面出击：把「想听的歌存下来断网也能听」（离线下载）、把「哪个平台又挂了」从用户播放时才发现变成主动预警（健康探测）、把「音源返回坏链却直接丢给播放器」这个最常被吐槽的播放失败根因彻底堵上（取链 URL 校验 + 自动兜底）。

---

## 新功能

### 离线下载管理

- 设置 → 下载设置 可开启「**启用下载功能**」，开启后曲目行与歌词页出现下载按钮。
- 下载在**后端落盘**（流式写文件，不再把整首歌读进渲染进程再传一遍），下载成功后登记进本地曲库，断网或上游接口全挂时这一首照样能播、能进收藏。
- 可配置项：
  - **下载路径**：默认保存在用户目录的 `downloads` 下；改路径会把已下载文件一起搬过去。
  - **文件命名方式**：歌名-歌手 / 歌手-歌名 / 仅歌名。
  - **下载配额**：超出后自动删除最早下载的歌曲（只删本软件登记的文件，不动其它数据）。
  - **同时保存歌词 / 封面**：同目录落 `.lrc` 与 `.jpg`，离线时歌词与封面不再回退占位图。
- 下载任务有队列与进度轮询；同名不覆盖、连点不会排队十个；支持取消、移除、清空已完成。
- 本地歌词/封面按曲库 id 经 `/api/download/lyric`、`/api/download/pic` 白名单回读，绝对路径不出后端。

### 平台健康主动探测

- 新增 `server/health-probe.js`：周期性探测各平台的**搜索**与**取链**两级能力，结果落盘 `userData/health.json`，重启后现场还在。
- 状态分四档：`正常 / 受限 / 不可用 / 未探测`；付费墙、需要登录态、依赖用户没导入的音源都**不计入「平台坏了」**——只标成「受限」并说明原因。
- **首屏横幅**：在线且某平台不可用时，直接提示「哪个平台、从什么时候开始不可用、原因」，并把入口指到设置页。
- 设置 → 平台健康：定时探测开关、探测间隔（默认 30 分钟）、各平台状态列表、故障记录（含状态迁移时间线）。
- 「**立即检测**」按钮手动触发一轮；离线模式与网易云离线时不探测、不报警，避免测试/离线环境被横幅刷屏。

### 音源取链 URL 校验与自动兜底

> 直接回应「音源导致的很多歌曲播放不出来」：截图里的 `音频地址无效或格式不支持（音源可能已失效）` 本质是洛雪音源取链路径只判断 `链接以 http 开头` 就返回，对死链/过期 vkey/错误页/试听占位不做内容校验，且第一层「成功」后跳过了会真正探测校验的原生 + 跨平台兜底链。

- `server/source-manager.js` 的取链环节现在用 `probeAudio` 探测前 64KB，识别错误页 / 试听占位 / 码率异常 / 时长不符 —— 校验不过即视为该音源失败，切到下一个音源；**全部失败才转交原生 + 跨平台兜底**（酷狗/网易云的同曲好链终于能被用上）。
- 播放失败（`MEDIA_ERR_SRC_NOT_SUPPORTED` / 网络错误）时，**自动换源重试一次**：强制重取链 + 跳过刚失败的音源，覆盖「探测时还好、播放前才过期」的短命链接（洛雪/QQ vkey 常见），且不无限循环。
- 60 秒**负缓存**：确认失效的链接短期内不再重复探测；`GUMAN_DISABLE_URL_PROBE=1` 可整体退回旧行为（逃生开关）。
- 顺手修了失败提示可能重复弹两次的问题（播放 catch 与 error 事件二选一，幂等）。

## 已知限制

- 离线下载依赖播放用的取链路径：未导入对应洛雪音源、或上游全挂时，下载会提示对应原因而非静默成功。
- 非官方接口可能随时变更：健康探测与四级取链均已带降级与超时，失败时展示原因而不是整体报错。
- 免费收录以 128K 为主；VIP 曲目通常只有翻唱或其他收录版本可播，界面会明确提示实际来源。
- 汽水搜索仍需先导入支持其搜索的洛雪音源。
- 未提供 QQ 登录入口。需要 QQ 原声时，可在 `userData/platform-auth.json` 写入 `{ "tx": { "uin": "你的QQ号", "qmKeyst": "cookie 里的 qm_keyst" } }`，取链会优先走 QQ 官方 vkey。
- 安装包未签名：Windows 弹 SmartScreen、macOS 未公证，需手动「仍要运行」。
- 平台健康探测的取链级只探有原生取链能力的平台；咪咕（跨源兜底）、汽水（依赖音源）不探 url 级，避免制造噪音。
