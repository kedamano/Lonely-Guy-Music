# 孤男音乐 v1.3.0 · 多平台聚合搜索与四级取链

> 这个版本重做了「除网易云之外都不太行」的根因：搜索上游换成官方匿名接口、结果统一清洗排序、同一首歌跨平台合并为一行，播放取链扩成四级降级并逐条校验，尽量做到**搜得到、播得稳、来源透明**。

---

## 新功能

### 聚合搜索（默认）

- 搜索面板最前新增「**聚合**」芯片：一次并发查询网易云 / QQ / 酷狗 / 酷我（可配置），**同一首歌合并为一行**。
- 合并规则：歌名归一化（NFKC + 繁转简 + 去括号版本）+ 歌手 + 时长，保留最佳来源为主，附带 `sources[]` 备选。
- 行内显示**来源徽标**（最多 4 个 + `+N`）与「**N 个来源**」；VIP、Live/伴奏/DJ/翻唱等版本标记只提示、不隐藏。
- 部分平台超时或失败不影响整体结果，meta 行会显示「部分平台失败：…」。
- 快速连续输入 / 切换平台会中止上一次请求，旧结果不会闪回。

### 平台搜索补齐

- **QQ 音乐**：改用官方匿名搜索接口（`client_search_cp`），排序与字段质量明显优于原 vkeys 方案，保留 vkeys 作为降级；返回真实总数、VIP 标记与各音质文件大小。
- **酷我**：新增原生搜索（伪 JSON 容错解析，禁用 eval），首条不再是 KTV/伴奏；`antiserver` 匿名取链。
- **咪咕**：新增 H5 原生搜索（无需导入音源即可搜）；汽水仍走洛雪音源，未导入时芯片置灰并说明原因。
- 所有平台结果统一后处理：清洗 HTML 实体、丢弃 30 秒以下铃声/片段、平台内去重、按相关度稳定排序、标记版本与 VIP。

### 换源播放

- 右键菜单新增「**换源播放 / 其他版本**」：优先使用聚合行内的其他来源，否则实时跨平台检索；列出「平台 · 歌名 · 版本 · 时长」供选择。
- 切换后播放队列中的曲目同步替换，并保留完整兜底链。
- 播放条新增「**实际播放：…**」，命中兜底或翻唱版本时 toast 明确提示，不静默替换。

### 取链可靠性

- 四级降级：**洛雪音源 → 平台原生 → 聚合备选 → 网易云/酷我/酷狗同曲兜底**。
- 每个平台候选地址先做 `Range` 探测：拒绝 HTML 错误页、酷我 181521 字节试听占位、过小文件、异常码率、时长偏差过大的片段（如 11 秒 preview）。
- 只有校验通过的地址才进缓存；缓存键包含音质，失败结果 60 秒负缓存，避免反复探测。
- QQ 无登录态时自动兜底网易云 / 酷我 / 酷狗，不再只有酷狗一条路。

### 音源运行时

- 多个洛雪音源**并发**解析（单源 8 秒超时），取首个成功结果；全部失败时按注册顺序汇总原因，不再被单个卡死音源拖住。
- 新增音源能力查询（search / musicUrl / lyric / pic），汽水等平台的可用性由已启用音源动态决定，导入/启停后立即刷新。
- 安全加固：`lx.request` 默认拒绝本机与私网字面量地址（SSRF 尽力防护，可用 `allowPrivateHost` 放行）；重定向次数上限与响应字节上限；`vm` 沙箱注释明确「不是安全边界」，并提供 `GUMAN_STRICT_SANDBOX=1` 严格模式。

### 其他

- 新增 `GET /api/platform/search-all`、`POST /api/platform/alternatives`；`/api/platform/url` 支持 `alternatives`。
- 平台清单新增 `available / reason / playback`，不可用平台芯片置灰并可点击查看原因。
- 缓存统计/清理覆盖单平台搜索与聚合搜索缓存。
- 新增 `opencc-js` 依赖（仅服务端懒加载，不进渲染层）。

## 已知限制

- 非官方接口可能随时变更：QQ / 酷我 / 咪咕均有降级路径与单平台超时，失败时展示原因而不是整体报错。
- 免费收录以 128K 为主；VIP 曲目通常只有翻唱或其他收录版本可播，界面会明确提示实际来源。
- 汽水搜索仍需先导入支持其搜索的洛雪音源。
- 未提供 QQ 登录入口。需要 QQ 原声时，可在 `userData/platform-auth.json` 写入 `{ "tx": { "uin": "你的QQ号", "qmKeyst": "cookie 里的 qm_keyst" } }`，取链会优先走 QQ 官方 vkey。
- 安装包未签名：Windows 弹 SmartScreen、macOS 未公证，需手动「仍要运行」。
