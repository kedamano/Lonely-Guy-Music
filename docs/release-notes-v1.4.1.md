# 孤男音乐 v1.4.1 发布说明

> 主题：**默认音源出厂内置 + 洛雪列表定时探测**

针对「音源导致的很多歌放不出来」这一核心痛点，v1.4.1 做了两件互补的事：
1. 把实测可用的 5 个社区音源作为**出厂默认**内置，首次启动自动导入并启用，开箱即听，不必再手动复制粘贴；
2. **定时探测**洛雪音源列表页，发现新地址/新音源就自动同步，让默认曲库始终是最新版，而不是一次写死。

---

## 一、默认音源出厂内置

设置页新增「默认音源」分区，列出以下 5 个社区音源（来自 lxmusic.ijinshan.com 逐条实测的可用源）：

| 音源 | 维护方 | 用途 |
|---|---|---|
| 六音音源 | 社区（六音） | 综合多平台，主力 |
| LX官方源 | 社区（pdone 仓库） | 基础平台，稳定备用 |
| Flower音源 | 社区（Flower） | 综合多平台，六音失效时替代 |
| Huibq音源 | 社区（Huibq） | 综合多平台，第三备用 |
| JuheApi音源 | 社区（JuheApi） | 综合多平台，尝试新源时可选 |

- 首次启动自动调用 `source-manager` 导入并启用，用户**无需手动操作**即可搜索/播放；
- 导入逻辑幂等：已导入且地址未变不会重复下载；地址变了（探测到新版）才重新导入；
- 单个音源导入失败只记 `warn`，**不阻断启动**，也不影响其它音源与官方接口兜底。

## 二、洛雪列表定时探测

新增 `server/sound-sources.js` 模块：

- **探测目标**：`https://lxmusic.ijinshan.com/sound-source/index.html`
- **解析**：用正则直接从页面抽取 `raw.githubusercontent.com/pdone/lx-music-source/.../<key>/latest.js` 直链（含页面「攻略更新于」日期），零 DOM 依赖、健壮；
- **同步**：探测到的地址覆盖内置默认集；页面上出现的新音源也会被纳入默认集；
- **落盘**：状态写入 `userData/sound-sources.json`（上次探测时间、失败原因、已发现列表、已导入记录），重启后现场仍在；
- **调度**：默认每 6 小时探测一次（可在设置页切换 6h / 12h / 每天 / 不自动），启动后延迟 2 分钟再探，避开起步资源争抢；
- **接口**：`GET /api/sound-sources`（快照）、`POST /api/sound-sources/probe`（手动立即更新）、`POST /api/sound-sources/config`（开关/间隔）。

## 三、设置页新增「默认音源」分区

- 显示上次探测时间、页面更新日期、失败原因；
- 每个音源显示状态：**未导入 / 已是最新 / 地址已更新**，以及当前地址；
- 「立即更新音源列表」按钮：手动触发一次探测与同步，并提示同步了几条；
- 「定时探测并同步」开关 + 探测间隔选择。

## 四、质量工程

- 新增 `scripts/sound-sources-check.js`（**17 项**，node-only，无需 Electron）：
  - 页面解析（6 个源、日期、名字映射、新源纳入）
  - 默认集基线（5 个出厂音源、URL 指向 main 分支）
  - 自动导入：首跑导入全部、二跑幂等不重复
  - 地址变更触发重新导入
  - 快照结构
- 全量 **306 项断言**（289 → 306）；无回归：version 5/5、proxy 12/12、platform-url 19/19、source-search 23、lx-url-validate 10/10、platform-search 61/61。

## 升级说明

- 已装 1.4.0 的用户：启动后自动更新提示，**首次启动会自动导入 5 个默认音源**（联网情况下；离线则记录 warn，联网后定时探测补齐）；
- 已手动导入过同名音源的用户：默认导入会复用现有音源（按名字去重），不会重复创建；
- 想要更细控制（如只留某几个源）：可在「自定义源管理」里手动增删，默认音源与手动导入的音源互不干扰。

## 已知限制（与之前一致）

- 音源为第三方社区维护，失效是常态；本版通过「内置默认 + 定时探测 + URL 校验 + 播放换源重试」四重手段缓解，但仍无法保证 100% 可播；
- 安装包未签名（Windows SmartScreen / macOS 未公证），首次运行需手动「仍要运行」。
