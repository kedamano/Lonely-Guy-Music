## 孤男音乐 v1.2.1

这次是个纯修复版，专治 **QQ 音乐 / 酷狗取链接不稳、经常报错、点了播不动** 的老毛病。

### 修复

- **新增平台原生取链层**：取链从「一条路走到底」改成三层降级——
  1. 第三方音源（洛雪）优先；
  2. 失败自动转**酷狗原生接口**：多音质 hash 并发 + 同名候选竞速；
  3. 再不行由 **QQ 兜底**。
  任何一层成功即返回，单点挂掉不再等于播放失败。
- **候选相似度打分**：按「歌名精确匹配 → 歌手 → 时长接近 → 版本变体」打分，翻唱/伴奏/Remix 不再被误选，召回上限从 6 放宽到 10。
- **修掉酷狗直链被浏览器拒播**：酷狗返回 `Content-Type: application/octet-stream`，音频元素直接拒绝加载；现在 `/api/proxy` 按扩展名纠正 content-type，直链能正常播。
- **剥离酷狗歌手字段里的 `<em>` 高亮标签**，搜索结果的歌手名不再带尖括号。
- **取链缓存 25 分钟**，同一首歌重复点击不再反复请求；失败不计入音源健康度，避免偶发误判把可用音源降权。
- CI：打包脚本显式 `--publish never`，修掉构建因缺少 token 而失败的问题。

实测 6 组（晴天 / 成都 / 海阔天空 × QQ / 酷狗）三层走完均可正常播放。

### 已知限制

- 酷狗匿名接口多数只给 128K，想听高音质需自行配置音源。
- 周杰伦等全 VIP 曲目，免费通道通常只能拿到翻唱版。
- 想走 QQ 官方 vkey，可在 `userData/platform-auth.json` 填 `{"tx":{"uin":"...","qmKeyst":"..."}}`。
