## 孤男音乐 v1.2.2

修掉「关于」面板里那个多出来的 `v`，同时把点击和加载的迟滞感压下去。

### 修复

- **「关于」面板版本号显示 `v v1.2.0`**：主进程已经传了 `v1.2.0`，界面又拼了一个前缀，于是成了两个 v。现在主进程只传裸版本号，界面侧再兜底剥一次前缀，任何一端都不会重复。新增 `scripts/version-check.js` 锁死这个契约，改回旧写法会直接测试失败。

### 点击更快

| 场景 | 改前 | 改后 |
|---|---|---|
| 回访发现页（点击 → 内容出现） | 再次请求接口 | 中位 **21ms** |
| 进音乐馆（首次 / 再次） | 每次请求 | 首次 590ms → 再次 **10ms** |
| 200 行列表监听器 | 约 1000 个 | **4 个**（事件委托） |
| 入场错峰延迟 | 最长 350ms | 最长 **120ms** |

### 加载更快

- **封面单次解码**：原来用「不可见探针 + background-image」两步走，同一张图要解码两次；现在 `<img>` 加载完直接淡入。
- **封面取缩略图**：网易云封面按 320×320 请求，不再拉 1000px 原图（实测单张从 273ms 降到 2ms，体积约 31KB）。
- **封面服务端缓存**：`/api/proxy` 增加图片 LRU（160 张 / 64MB）+ `max-age=604800`，同一张封面二次访问零外网往返；上游偶发 5xx 自动重试一次。
- **读接口缓存**：个性化推荐、音乐馆、歌单详情/曲目、搜索、平台搜索、歌词等加 60 秒内存缓存与并发去重；登录态变化自动失效，不会串号。
- **播放进度独立落盘**：原来每 5 秒要把收藏/历史/歌单整包序列化一次，现在拆到独立 key 并做 1 秒合并，播放中不再卡一下。
- **收藏查询改 Set**：长列表渲染从 O(n²) 降为 O(n)。
- **i18n 增量翻译**：简体中文下不再每次路由都重扫全文档；英文/繁体只翻译新建的视图子树。
